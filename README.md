# А101 · Родные кварталы

Локальный интерактивный прототип по обновлённому макету Figma, экран **1920 × 1080**. Обычные HTML, CSS и JavaScript: сборка и установка npm-пакетов не нужны.

## Открыть локально

Откройте `index.html` в браузере. Это просмотр в мокапе монитора: внутренний экран всегда 1920 × 1080, внешний масштаб подстраивается под окно. Прокручивайте страницу внутри монитора или переключайте четыре состояния сверху. Кнопка справа включает полноэкранный режим.

Если браузер ограничивает локальные iframe, запустите в этой папке:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Затем откройте <http://127.0.0.1:4173/>. Остановка сервера — Ctrl+C. На macOS можно дважды нажать `Запустить.command`.

`scene.html` — сама страница без внешнего мокапа; для сверки используйте окно 1920 × 1080.

## GitHub Pages

Поместите **содержимое этой папки** в корень репозитория, включая `assets/` и `.nojekyll`. Пути к локальным ресурсам относительные, поэтому прототип работает и по адресу репозитория вида `https://username.github.io/repository/`.

Загрузите файлы проекта в репозиторий. Фоновое видео подключено по прямой HTTPS-ссылке с CDN А101 и не входит в папку проекта. Распакуйте архив перед загрузкой: в репозиторий нужно загрузить его содержимое, а не ZIP-файл.

В репозитории откройте **Settings → Pages → Build and deployment → Deploy from a branch**, выберите ветку с файлами и папку **/(root)**, затем Save. [Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Что внутри

- `index.html`, `viewer.css`, `viewer.js` — мокап экрана и переключение состояний.
- `scene.html`, `style.css`, `app.js` — страница и интерактивное поведение скролла, фильтров и галереи.
- `assets/` — шрифты Euclid Circular A Regular/Medium, изображения и SVG из макета.

Видео автоматически воспроизводится без звука и зациклено (`autoplay`, `muted`, `loop`, `playsinline`). Оно загружается напрямую с <https://cdn.a101.ru/mmedia/p/pb/v/ea49af1fe4.mp4> и находится под двумя слоями градиента; локальный постер отображается до загрузки первого кадра. Для воспроизведения нужен интернет и доступность видео на CDN А101.

Заголовок уходит вверх с обычным скроллом. Фильтры закрепляются под шапкой. В прозрачной шапке пункты меню при наведении становятся #D5D6DC, в белой — #E8363D.

Макет: <https://www.figma.com/design/fknoyjL2gAd5ZjOf4hX5qn/?node-id=2108-5310>.

Фильтры и всплывающие окна демонстрационные: подключение к каталогу квартир и отправка заявок не предусмотрены. В галерее используются два исходных фото из макета.
